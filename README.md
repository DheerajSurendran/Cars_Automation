# Cars Service Website Automation Testing

## 📌 Project Overview

This project automates the major functionalities of the Cars Service Website using **Selenium WebDriver**, **Java**, and **TestNG**. The automation framework follows the **Page Object Model (POM)** design pattern for better maintainability and reusability.

**Website:** https://sathu.pythonanywhere.com/

---

## 🎯 Objectives

- Automate repetitive functional test cases.
- Reduce manual testing effort.
- Improve regression testing efficiency.
- Validate application functionality through automated scripts.

## ▶️ How to Run

1. Clone the repository

```
git clone <repository-url>
```

2. Import as Maven Project into Eclipse.

3. Update Maven Dependencies.

4. Execute

```
testng.xml
```

or run individual test classes.
